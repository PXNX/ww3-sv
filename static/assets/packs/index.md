# World War 3 WebP asset pack

**92 WebP files in total.**

All images are transparent WebP files, rendered at 512 px unless noted. Nothing here is wired into
the game — this is a ready-to-use asset folder. Paths below are relative to this directory and can
be served from `/assets/packs/...`.

`mascot/`, `stickers/mascot/` and `emoji/` are new original vector art drawn for this pack.
The `stickers/` subfolders with cameos and game art are conversions of the existing SVG artwork in
`static/assets/`, kept in their original style.
